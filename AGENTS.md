# Repository instructions

## Agent skills

### Issue tracker

GitHub Issues and the linked GitHub Project hold live state. `.scratch/` holds synchronized local mirrors. See `docs/agents/issue-tracker.md`.

### Triage labels

Use `bug` or `enhancement` with one configured triage status. See `docs/agents/triage-labels.md`.

### Domain docs

Use the single-context layout in `CONTEXT.md` and `docs/adr/`. See `docs/agents/domain.md`.
