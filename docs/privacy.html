open.md privacy

Effective August 18, 2026

open.md is local-first. It does not require an account, show advertising, collect analytics, or upload documents, file paths, local images, or reading preferences.

Files and editing

The app reads only files selected through the file picker, drag and drop, command-line launch, or the operating system's Open with flow. Opening a file does not write to it. A file changes only when the user edits and saves it, or while the user has explicitly enabled autosave.

Images, links, and network access

Relative local images can be displayed under a bounded local-file policy. Remote Markdown images are not fetched. External links are opened by the operating system and the destination service applies its own policy.

The current app has no telemetry, cloud sync, advertising, or production updater. A future Microsoft Store EXE release may request release metadata and signed update artifacts from a documented HTTPS endpoint; it will not send document content or local paths.

Local settings

Native settings are stored under %APPDATA%\com.gvastethecreator.openmd. Reader preferences are stored in the application's local WebView data. Optional path-to-theme preferences may contain local paths and remain on the device.

File associations

Packaged builds may register .md, .markdown, and .txt for Open with. open.md never silently takes over the user's default application.

Deletion

Uninstalling open.md does not delete user documents. Application preferences may remain until the user removes the app settings directory or local WebView profile.

Security and contact

Use the repository's private security-reporting process for vulnerabilities. Do not place private documents or sensitive paths in public issues.

Privacidad de open.md

Vigente desde el 18 de agosto de 2026

open.md funciona de manera local. No requiere cuenta, no muestra publicidad, no recopila analíticas y no sube documentos, rutas, imágenes locales ni preferencias.

Archivos y edición

La aplicación lee únicamente archivos elegidos por el usuario mediante el selector, arrastrar y soltar, la línea de comandos o Abrir con. Abrir un archivo no lo modifica. Solo cambia cuando el usuario edita y guarda, o cuando habilitó explícitamente el guardado automático.

Imágenes, enlaces y red

Puede mostrar imágenes locales relativas bajo una política acotada. No descarga imágenes remotas desde Markdown. Los enlaces externos se abren mediante el sistema operativo.

La versión actual no incluye telemetría, sincronización en la nube, publicidad ni un updater de producción. Una futura versión EXE para Microsoft Store podrá consultar metadata y artefactos firmados en un endpoint HTTPS documentado, sin enviar documentos ni rutas locales.

Configuración local

La configuración nativa se guarda en %APPDATA%\com.gvastethecreator.openmd. Las preferencias de lectura se guardan en los datos locales del WebView. Las asociaciones opcionales entre rutas y temas permanecen en el dispositivo.

Asociaciones y eliminación

Las compilaciones empaquetadas pueden registrar .md, .markdown y .txt para Abrir con, pero nunca reemplazan silenciosamente la aplicación predeterminada. Desinstalar open.md no elimina los documentos del usuario.

Seguridad y contacto

Reporta vulnerabilidades mediante el proceso privado del repositorio. No publiques documentos ni rutas sensibles en issues públicos.
